`Next.js/React` `Node.js/Express` `FastAPI` `MongoDB` `Claude API` `n8n` `Docker`

---

**[Smart Supply Forecaster](https://github.com/SaadTadja/smart-supply-forecaster)** — closed-loop MLOps pipeline

FastAPI serving with prediction logging. Airflow monitors a **14-day rolling RMSE** and triggers retraining. Chronological validation with no data leakage, plus a promotion audit — a new model ships only if it beats the one in production.

`Python` `XGBoost` `MLflow` `Airflow` `Docker`

---

**[Athena Core](https://github.com/SaadTadja/athena-core)** — decision-support platform

Revenue forecasting with Random Forest (**R² ≈ 0.92** on the test set), anomaly detection with Isolation Forest, a recommendation engine, RFM segmentation and KPIs, with auto-generated strategic frameworks.

`Python` `scikit-learn` `Streamlit`

---

**[AI Compass](https://ai-dashboard-roan-one.vercel.app)** — full-stack LLM comparison app · [source](https://github.com/SaadTadja/AI-Compass)

Deployed web app comparing LLMs on published benchmarks and pricing: relational data model, REST API with filtering and sorting, responsive React dashboard.

`Next.js` `TypeScript` `Prisma/PostgreSQL`
